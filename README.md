# JahitanRapi.id — Tailoring Service Landing Page

JahitanRapi.id adalah proyek **tugas kuliah** berupa pembuatan landing page untuk layanan jahit dan modiste. Proyek ini dibuat untuk mempraktikkan dasar-dasar pengembangan web, khususnya penyusunan struktur halaman menggunakan HTML serta pembuatan antarmuka responsif dengan Tailwind CSS.

Website ini menggunakan konsep layanan jahit sebagai tema desain, dengan tujuan menyajikan informasi bisnis secara terstruktur, mulai dari profil layanan hingga formulir konsultasi dan pemesanan.

> **Project Type:** Academic Project / College Assignment  
> **Project Focus:** Landing Page Development

## ✨ Features

- **Responsive Layout** — Tampilan halaman yang menyesuaikan ukuran layar.
- **Navigation Bar** — Navigasi menuju bagian utama website.
- **Hero Section** — Bagian pembuka yang menampilkan gambaran layanan jahit.
- **About Section** — Informasi mengenai profil layanan.
- **Services Section** — Daftar layanan seperti custom outfit, permak pakaian, jahit seragam, dan konsultasi desain.
- **Testimonials Section** — Bagian yang menampilkan contoh testimoni pelanggan.
- **Contact & Order Form** — Formulir tampilan untuk konsultasi dan pemesanan.
- **Footer** — Informasi kontak dan tautan tambahan.

## 🛠️ Technologies

- **HTML5** — Menyusun struktur dan konten halaman web.
- **Tailwind CSS** — Membantu styling dan pengaturan layout menggunakan utility classes.
- **Tailwind CSS Browser CDN** — Memuat Tailwind CSS langsung melalui CDN untuk kebutuhan pengembangan proyek.

## 🚀 How to Run

1. Clone repositori ini:

   ```bash
   git clone https://github.com/USERNAME/jahitanrapi-id.git
   ```

2. Masuk ke direktori proyek:

   ```bash
   cd jahitanrapi-id
   ```

3. Buka file `index.html` menggunakan browser.

Pastikan koneksi internet tersedia agar Tailwind CSS dan gambar yang dimuat dari sumber eksternal dapat ditampilkan.

## ⚠️ Project Limitations

Proyek ini berfokus pada pembuatan **landing page frontend** sebagai tugas kuliah, sehingga belum mencakup keseluruhan fungsi website bisnis yang sebenarnya.

- Formulir pemesanan belum terhubung ke backend atau database.
- Tombol pengiriman formulir belum memproses maupun mengirim data pesanan.
- Informasi layanan, testimoni, dan kontak digunakan sebagai konten pada halaman demo.
- Website belum memiliki sistem autentikasi, pengelolaan pesanan, atau dashboard administrasi.
